# IESE Master in Finance: coursework

Quantitative cases and assignments from the IESE Master in Finance (Madrid, class of 2027), with the code that
reproduces every result. One folder per course, one subfolder per case.

| Course | Case | What it asks | Report |
|---|---|---|---|
| Predictive Statistics in Finance | [Can we predict stock returns?](predictive-statistics/stock-returns-case) | Do stock characteristics forecast next month's return out of sample? Pooled OLS, fixed effects and an honest 2020-2025 test on 1.06 million CRSP stock-months | [PDF](predictive-statistics/stock-returns-case/report/report.pdf) |
| Predictive Statistics in Finance | [Forecasting Bitcoin volatility](predictive-statistics/bitcoin-volatility-case) | How predictable is tomorrow's Bitcoin risk, and which forecast should a fund use? ARCH, GARCH Normal and Student-t against realized variance, expanding vs two-year rolling windows, 608 out-of-sample days | [PDF](predictive-statistics/bitcoin-volatility-case/report/report.pdf) |
| Predictive Machine Learning in Finance | [Predicting employee attrition](predictive-ml/employee-attrition-case) | Which employees will leave, and why? Decision trees of increasing depth, cross-validation, confusion matrices and a logistic-regression benchmark on 1,470 IBM HR records | [PDF](predictive-ml/employee-attrition-case/report/report.pdf) |
| Predictive Machine Learning in Finance | [Credit card churn](predictive-ml/credit-card-churn-case) | Which cardholders will close their account? K-Nearest Neighbours, why scaling decides who is a neighbour, k by cross-validation and a proper preprocessing pipeline on 10,127 customers | [PDF](predictive-ml/credit-card-churn-case/report/report.pdf) |
| Predictive Machine Learning in Finance | [Lending Club: who gets the loan?](predictive-ml/lending-club-case) | Which applicants should a lender decline? Leakage, a decision tree, Random Forest and XGBoost on 38,770 loans, trained to 2010 and tested on 2011, judged on the approved book's default rate and explained with SHAP | [PDF](predictive-ml/lending-club-case/report/report.pdf) |
| Predictive Machine Learning in Finance | [FIFA 22 players and PCA](predictive-ml/fifa-players-pca-case) | How many real dimensions hide in 35 skill ratings? PCA on 17,107 outfield players: scree plot, loadings, positions in component space and player similarity | [PDF](predictive-ml/fifa-players-pca-case/report/report.pdf) |
| Predictive Machine Learning in Finance | [Bank churn call list](predictive-ml/bank-churn-case) | Who should a retention team call? Logistic regression against linear, polynomial and RBF SVMs on 10,000 customers, C and gamma, Platt calibration and ranking by deposits at risk | [PDF](predictive-ml/bank-churn-case/report/report.pdf) |

Course materials and licensed data (CRSP via WRDS) are not included.
