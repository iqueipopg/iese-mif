# IESE Master in Finance: coursework

Quantitative cases and assignments from the IESE Master in Finance (Madrid, class of 2027), with the code that
reproduces every result. One folder per course, one subfolder per case.

| Course | Case | What it asks | Report |
|---|---|---|---|
| Predictive Statistics in Finance | [Can we predict stock returns?](predictive-statistics/stock-returns-case) | Do stock characteristics forecast next month's return out of sample? Pooled OLS, fixed effects and an honest 2020-2025 test on 1.06 million CRSP stock-months | [PDF](predictive-statistics/stock-returns-case/report/report.pdf) |
| Predictive Statistics in Finance | [Forecasting Bitcoin volatility](predictive-statistics/bitcoin-volatility-case) | How predictable is tomorrow's Bitcoin risk, and which forecast should a fund use? ARCH, GARCH Normal and Student-t against realized variance, expanding vs two-year rolling windows, 608 out-of-sample days | [PDF](predictive-statistics/bitcoin-volatility-case/report/report.pdf) |

Course materials and licensed data (CRSP via WRDS) are not included.
